## حالة العقود

الإعادة مدعومة في الفرونت والباك بعد PR #170 وترحيل `0012_outing_rounds`؛ إعداد
البناء الحالي هو `EXPO_PUBLIC_SESSION_ROUNDS_ENABLED=true`. لا تنسخ إعداد
الخادم القديم ذي الجولة الواحدة إلى النسخة الحالية.

الباك يدعم تفاصيل المطعم وفلترة الحي/المطبخ والمغادرة/الإزالة وإرسال push.
توفر المسار لا يعني أن الواجهة استكملت استهلاكه. المرجع لحالة الشاشات هو جدول
[سبرنت ٢ و٣](Sprint-2-3-Frontend.ar.md)، والقبول النهائي يحتاج جهازًا ومتصفح ضيف.

تغييرات هذا التنظيم لا تضيف ميزات أو جداول أو مسارات API. عند تغيير السلوك
لاحقًا، حدّث شرحه وعقده ورسمه المتأثر ودليل التحقق في التغيير نفسه.
