قرارات ثابتة / Approved rules
  • حساب للمنظّم؛ التصفح والانضمام كضيف بدون حساب. / Organizer account; public browsing and guest access.
  • ننتظر جاهزية الجميع ثم يبدأ المنظّم الاقتراحات. بعدها تُغلق العضوية. / Everyone ready; organizer starts generation; membership locks.
  • تُحفظ الإجابة قبل الانتقال؛ اعتماد المراجعة يؤكد اكتمال التصويت. / Save before advancing; review confirmation marks completion.
  • الحسم تلقائي عند اكتمال الجميع، أو مبكر بتأكيد المنظّم. / Automatic completion or confirmed early end.
  • التأييد من كامل المجموعة؛ تعادل الإعجابات الإيجابي يُحسم بالترتيب المحفوظ. دون إعجابات لا فائز. / Full-group denominator; stored ranking breaks positive ties; zero likes means no winner.
  • إعادة المحاولة بنفس الجلسة والدعوة والمشاركين، وجولة جديدة. / Retry in the same session with a new round.

Organizer account

Correct the name label. The current React Native form already says Name; retain that fix.

المحتوى والحقول Fields

  • الاسم: مطلوب، دون فراغات زائدة؛ وليس «اسم الجلسة».

    Name: required, trimmed; never call it Session name.

  • رقم الجوال: حقل واحد بصيغة 05XXXXXXXX؛ اقبل الأرقام العربية ووحّدها في الخادم.

    Phone: one input, 05XXXXXXXX; accept Arabic digits and normalize on the server.

الأزرار والتنقل Actions

  • إرسال رمز التحقق ← التحقق؛ لدي حساب ← دخول بالهاتف؛ رجوع ← التصفح العام.

    Send code → verification; Existing account → phone login; Back → public browsing.

الحالات المطلوبة States

  • الفراغ أو الصيغة الخاطئة: رسالة عند الحقل بعد الإرسال. أثناء الإرسال: امنع تكرار الطلب.

    Empty/invalid fields: show an inline message after submit. Sending: disable a second request.

  • فشل الإرسال: احفظ المدخلات وأظهر «إعادة المحاولة». لا يعتبر الحساب منشأ قبل نجاح التحقق.

    Delivery failure: keep entered values and offer Retry. Account creation succeeds only after verification.

ملاحظات التنفيذ Build notes

  • الحساب مطلوب للمنظم فقط؛ يبقى التصفح وضيف المتصفح متاحين.

    Only the organizer needs an account; browsing and browser guests stay accessible.

  • الدخول يستخدم حقل الهاتف نفسه دون طلب الاسم مرة أخرى.

    Login uses the same phone field without asking for the name again.

Participants and readiness

أبق صفوف المشاركين ورمز المشاركة. أضف إزالة المنظم ومغادرة المشارك وعدد الجاهزين وزر توليد مشروطًا.

المحتوى والحقول Fields

  • رمز الجلسة واسمها ووقتها ومنطقتها وعدد المشاركين والجاهزين.

    Session code, name, time, area, total participants and ready count.

  • الصفوف تعرض الاسم وشارة المنظم والجاهزية فقط؛ دون القيود الشخصية.

    Everyone: My preferences. Organizer: Share invite, remove another participant, Generate suggestions when everyone is ready.

  • للمشارك: المغادرة قبل التوليد بعد التأكيد. لا إزالة للمنظم نفسه ولا نقل ملكية ضمن هذا النطاق.

  • بدء التوليد: يقفل الانضمام والمغادرة والإزالة. وصول شخص أو تعديل تفضيل يحدث الجاهزية قبل التوليد.

ملاحظات التنفيذ Build notes

  • لا تولد تلقائيًا عند جاهزية آخر شخص؛ يبدأ المنظم بعد جاهزية الجميع.

    Do not generate automatically on the last Ready. Organizer starts after everyone is ready.

  • الجاهزية ليست حضورًا ولا مجرد فتح الشاشة.

    Ready is not attendance and not simply opening the screen.

المحتوى والحقول Fields

    Cuisine likes optional. Budget min/max in SAR per person, distance limit in km from the meeting area.

  • الحساسية أو القيود: «لا يوجد» أو اختيارات صريحة؛ احتياجات الجلسة: «لا اشتراط» أو اختيارات. غياب الإجابة لا يعني «لا يوجد».

الأزرار والتنقل Actions

الحالات المطلوبة States

  • التحقق: الأدنى لا يتجاوز الأعلى، والمسافة موجبة، والإجابات المطلوبة مكتملة. فشل الحفظ يبقي النموذج ولا يعلن الجاهزية.

    Validation: minimum ≤ maximum, positive distance, required answers complete. Save failure keeps the form and never marks Ready.

  • بعد التوليد: للقراءة فقط. الإعادة تبقي القيم وتلغي جاهزية جميع المشاركين.

    After generation: read only. Retry carries values forward but resets every participant to not ready.

ملاحظات التنفيذ Build notes

  • النص: «نستخدم شروطك لاستبعاد الاقتراحات غير المناسبة، ولا نعرض تفاصيلها لبقية المشاركين».

    Copy: Your constraints are used to filter suggestions. They are not shown to the other participants.

  • لا تعرض حساسية منسوبة لشخص أو قائمة مسببات مجهولة الأسماء أو من تسبب بعدم التطابق. نقص حقيقة شرط أساسي يستبعد المطعم.

    Never expose a named allergy, anonymous allergen list, or who caused a no-match result. Unknown hard-limit facts exclude the restaurant.
