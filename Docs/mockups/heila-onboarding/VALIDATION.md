# التحقق من شاشات هيلة

التاريخ: 24 نوفمبر 2026. أساس الفرع: `deployment` عند `92e5aa4`.

## الفحوص المنفّذة

- نجح `npm run check` من جذر المستودع، بما يشمل TypeScript وحدود المعمارية واختبارات الواجهة المسجلة في الأمر.
- نجح `node --check Docs/mockups/heila-onboarding/source/app.js`.
- نجح فحص فروق Git للمسافات الزائدة.
- استجاب المصدر وملفات CSS وJavaScript والأصول المحلية المشار إليها بحالة HTTP 200.
- لا توجد صور مفقودة أو أخطاء JavaScript ظاهرة في سجل المتصفح أثناء الجولة.

## تجربة المتصفح

- جُرّبت الشاشات عند عرض 390 بكسل، والتفضيلات عند عرض 320 بكسل. لا يوجد تمرير أفقي.
- التالي والنقاط تنقل بين الشاشات الثلاث فقط. بعد الثالثة يتغير الزر إلى «افتح ذوق»، وجُرّب الانتقال الفعلي إلى تطبيق ذوق.
- اختيار السعودي أو الإيطالي يغيّر صورة الاقتراح واسمه وسببه ورد هيلة وحالة الاختيار.
- بعد إصلاح التداخل، ظهر رد هيلة أسفل الاقتراح بمسافة واضحة عند العرضين، وبقي السبب داخل البطاقة. الصور في `evidence/` توثق المعاينة؛ صورة التفضيلات بعد الإصلاح.
- جُرّبت إعادة المشهد وإيقاف الحركة واستئنافها والعودة إلى الشاشة الأولى بالنقاط.
- روجع مسار `prefers-reduced-motion` في الكود؛ لم يُغيّر إعداد الحركة في نظام التشغيل خلال هذا التحقق.

## حدود التحقق

هذا عرض ويب مستقل ببيانات توضيحية. لم تُدمج الشاشات في Expo ولم يُختبر عرضها كشاشات React Native. لا يغيّر هذا التسليم API أو قاعدة البيانات أو تسجيل الدخول أو حفظ التفضيلات. زر «تخطّي» رابط لنفس وجهة زر النهاية.
