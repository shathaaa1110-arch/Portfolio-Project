# Thouq

A group meal decision app. Participants join a shared session, enter their preferences and constraints, and the app recommends three restaurants for the group to vote on.

---

## Objectives

1. The user is not overwhelmed when ordering meals.
2. Filtering by budget and cuisine type.
3. Speeding up the group's decision.

> To be reframed as S.M.A.R.T objectives.

## Scope (MoSCoW)

### Must Have

- Session with a shareable code — no accounts, no sign-in
- Entry of preferences, constraints, and allergies for each participant
- Recommendation engine: strict exclusion, then ranking by score
- A written reason displayed for each recommendation
- Three recommendations and group voting
- Restaurant database tagged with cuisine types, constraints, and price range

### Should Have

- Restaurant photos
- Handling incomplete responses, and showing how many participants responded
- Session expiry

### Could Have

- User ratings and reviews

### Would Have

- Reservations
- AI
- Publishing the app to the app store
