# أيقونة تطبيق ذوق

أُضيفت هوية هيلة المعتمدة إلى إعدادات البناء في ٢٤ نوفمبر ٢٠٢٦.
تستخدم الأيقونة الشخصية الخضراء مع الوشاح الذهبي والخلفية الكريمية.

## أي ملف أبدأ فيه؟

ابدأ بملف `frontend/app.json`. هذا الملف يخبر Expo بالصور التي يستخدمها
عند تجهيز التطبيق للجوال أو تصدير الموقع. لا تحتاج إلى إضافة مكوّن React
لعرض أيقونة التطبيق على شاشة الهاتف.

| الإعداد | وظيفته | الصورة |
|---|---|---|
| `expo.icon` | الأيقونة الأساسية، ومنها الأجهزة القديمة | `haila-icon.png` |
| `expo.ios.icon` | أيقونة الآيفون بدل مجلد Expo الافتراضي | `haila-icon.png` |
| `expo.web.favicon` | أيقونة تبويب المتصفح | `haila-icon.png` |
| `expo.android.adaptiveIcon.foregroundImage` | الشخصية فوق الخلفية في أندرويد | `haila-adaptive-foreground.png` |
| `expo.android.adaptiveIcon.monochromeImage` | الشكل الذي يلوّنه أندرويد عند تفعيل الأيقونات المتوافقة مع الثيم | `haila-monochrome.png` |
| إعداد `expo-splash-screen` | هيلة أثناء بدء تشغيل النسخة المبنية | `haila-adaptive-foreground.png` |

الصور الثلاث محفوظة في `frontend/assets/images/branding/`، ومقاس كل منها
`1024 × 1024`. الأيقونة الأساسية مربعة وغير شفافة؛ النظام يضيف شكل الحواف.
صورتا أندرويد شفافتان، مع مساحة فارغة حول الشخصية حتى لا تقصها أقنعة
الأيقونات الدائرية والمربعة. لون خلفية أندرويد وشاشة البداية هو `#FFF3DA`.

## كيف تظهر في التطبيق؟

1. يقرأ Expo المسارات من `app.json`.
2. يجهز صور النظام بالمقاسات المطلوبة عند بناء iOS أو Android.
3. يستخدم المتصفح الأيقونة عند تصدير الويب ونشره.
4. عند تشغيل النسخة المثبتة، تظهر هيلة في شاشة البداية، ثم تفتح رحلة التطبيق المعتادة.

تغيير أيقونة الهاتف أو شاشة البداية يحتاج إلى بناء نسخة جديدة وتثبيتها؛
تحديث JavaScript وحده لا يغيّر أيقونة التطبيق المثبتة. نسخة الويب تحتاج
إلى تصدير ونشر جديدين، وقد يحتفظ المتصفح بالأيقونة القديمة مؤقتًا في الذاكرة المخبأة.
Expo Go لا يثبت أن شاشة البداية النهائية مطابقة؛ راجعها في نسخة preview أو release.

## حدود التغيير

هذا تعديل لأصول الهوية وإعدادات البناء. لم تتغير الشاشات أو التصفح أو
التسجيل أو الاقتراحات. لا توجد طلبات API جديدة، ولا تغيير في قاعدة البيانات
أو ERD أو حدود الميزات أو `architecture.json`.

## التحقق

نُفذت الفحوصات التالية في ٢٤ نوفمبر ٢٠٢٦، على تغيير مبني على `deployment`
عند `92e5aa4`:

- نجح `npm run check`، ويشمل TypeScript وحدود المعمارية واختبارات الفرونت.
- نجح `npx expo config --type public --json`، وجميع مسارات الصور موجودة.
- الصور الثلاث مربعة بمقاس 1024 بكسل. صورة iOS غير شفافة. تقع الشخصية في
  صورتي أندرويد داخل دائرة الأمان: نصف قطر الرسم الظاهر نحو 290 بكسل، أقل
  من حد الأمان البالغ نحو 313 بكسل على هذه المساحة.
- نجح `npx expo export --platform web` وأنتج `favicon.ico` وربطه في الصفحة.
- نجح `npx expo prebuild --no-install` لـ iOS وAndroid في نسخة مؤقتة، بمعرفات
  محلية للفحص فقط. تطابقت صورة iOS الناتجة مع الأيقونة، وظهرت طبقات أندرويد
  العادية وmonochrome في كثافات العرض الخمس، مع الخلفية الكريمية.
- راجعنا [معاينة أقنعة الأيقونة](branding/haila-app-icon-preview.png) للتأكد من عدم قص الشخصية.
- نجح `git diff --check`.

هذا تحقق من الإعدادات والتصدير وتجهيز ملفات النظام، وليس تقرير تثبيت على
جهاز حقيقي أو بناء IPA/APK نهائي. لا تزال معاينة الأيقونة وشاشة البداية
على النسخة الجديدة المثبتة مطلوبة بعد البناء.
