# Thouq app (frontend)

The Thouq mobile app, built with Expo.

Screens so far: Sign up.

## Before you start
Install Node.js and Git. On Windows, run:
```
winget install OpenJS.NodeJS.LTS
winget install Git.Git
```
Then close the terminal, open a new one, and check they work:
```
node -v
git --version
```
Install the Expo Go app on your phone from the App Store or Google Play.

You don't need to install Expo itself. `npm install` brings it with the project.
## Run it
Open a terminal in the frontend folder and run:
```
npm install
npx expo start
```
A QR code will show up. Scan it with your phone camera (iPhone) or with Expo Go (Android), and the app opens on your phone.

Not opening? Make sure your phone and laptop are on the same Wi-Fi, or run `npx expo start --tunnel` instead.
